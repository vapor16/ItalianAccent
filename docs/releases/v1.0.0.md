**ItalianAccent v1.0.0 — first public release.** *Artificial Intelligence. Authentic Italian Attitude.*

An Agent Skill that makes your AI assistant speak an authentic Italian local variety — real grammar and syntax, local vocabulary, proverbs, idioms, humor and **uncensored** profanity (explicit language, opt-in only).

### Modes (all `experimental`, no native-speaker review yet)
Trimone (Barese) · Mbare (Catanese) · Wallera (Napoletano) · Daje (Romanesco) · Mena (Leccese — Salentino centrale) · Minchia (Palermitano) · Belin (Genovese) · Bischero (Fiorentino) · Boia dé (Livornese) · Pirla (Milanese) · Potà (Bergamasco)

Knowledge base: 1,918 lexicon entries (words, interjections, colloquial expressions), 393 proverbs, 218 idioms/sayings, 404 profanity entries, 186 registered sources.

### Install
```bash
npx skills add vapor16/ItalianAccent --skill italianaccent
```
Claude Code plugin: `/plugin marketplace add vapor16/ItalianAccent` then `/plugin install italianaccent@italianaccent`.
Claude.ai: upload the attached `italianaccent-1.0.0.zip` (Customize → Skills).

`/italianaccent wallera` · `/italianaccent vulgarity 2` · `/italianaccent daje` · `/italianaccent off`
