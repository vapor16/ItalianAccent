# Privacy Policy — ItalianAccent

_Last updated: 2026-11-26_

ItalianAccent is an open-source, declarative Agent Skill made only of Markdown and JSON files (instructions,
dialect profiles, vocabulary, proverbs). It contains no executable code that runs when you use it.

## What ItalianAccent does not do

ItalianAccent itself:

- does not collect, transmit, store or retain any user data;
- has no backend, server, database, analytics, telemetry or tracking;
- does not require credentials, API keys, accounts or access to your files, environment variables or other
  services;
- makes no network requests.

## How your conversation is processed

When you activate ItalianAccent, the AI platform you use (for example Claude Code, Claude.ai or another Agent
Skills host) reads the skill's files and uses them, together with your conversation, to generate replies. That
processing happens entirely within the host platform. ItalianAccent does not control and is not responsible for how
the host platform, or any tool you use to install the skill (for example the Skills CLI, Git or a plugin
marketplace), collects, processes or retains data. Please refer to their own privacy policies.

## Support and contributions

Support is provided through [GitHub Issues](https://github.com/vapor16/ItalianAccent/issues). Issues, pull requests
and discussions are public: do not include personal, confidential or sensitive information in them.

## Changes

Changes to this policy are published in this file in the
[ItalianAccent repository](https://github.com/vapor16/ItalianAccent). Questions can be raised through GitHub Issues.
